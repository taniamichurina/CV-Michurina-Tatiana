## Исследовательский опыт

### Анализ генетических аспектов шизофрении в мультиэтнической когорте

**Genotek | Выпускная квалификационная работа, 2026**

**Цель проекта:** исследование генетических факторов риска развития шизофрении в российской популяции (3642 участника) и оценка предсказательной способности полигенных шкал риска.

**Выполненные задачи:**
- Контроль качества данных генотипирования (QC).
- Анализ популяционной структуры с использованием метода главных компонент (PCA).
- Выполняла полногеномный поиск ассоциаций (GWAS).
- Полногеномный поиск ассоциаций (GWAS) с применением логистической регрессии и учётом ковариат (пол, возраст).
- Анализ генетических ассоциаций и функциональная аннотация с использованием FUMA.
- Построение полигенных шкал риска (PRS) на основе собственных и внешних GWAS статистик.
- Сравнение моделей и оценка их предсказательной способности.

**Основные результаты:**
- Исследованы генетические ассоциации, связанные с риском развития шизофрении в российской когорте.
- Выделены гены-кандидаты NCAM2 и PTPRD.
- Оценена переносимость внешних полигенных шкал риска на российскую выборку.
- Наилучшая из протестированных внешних моделей PRS показала AUC = 0,68.
- Наилучшая мультиэтническая модель с учётом ковариат достигла AUC = 0,74.
